# Codex Assistant

Оверлей-справочник для ролевых проектов. Законы и правила доступны для Majestic RP. В GTA 5 RP и «Россия Онлайн» можно выбрать сервер.

## Возможности

- поиск по кодексам, тексту статьи, пояснениям, исключениям и санкциям;
- вкладки законов и правил, фильтры по разделам и категориям;
- список серверов Majestic, загружаемый из базы проекта;
- офлайн-кэш законов и правил;
- горячая клавиша, авто-скрытие, настройка прозрачности и темы;
- автоматическое получение новых сборок из GitHub Releases.

## База Majestic

Приложение читает список серверов из `repo_structure.json`, кодексы из `laws/` и общие правила из `rules/` в [`dev-onewizard/majestic-laws-db`](https://github.com/dev-onewizard/majestic-laws-db). В случае недоступности файлов запрос идёт в [исходную базу](https://github.com/alamantik/majestic-laws-db). База охватывает 19 серверов Majestic. Загруженные данные доступны офлайн.

## Запуск и разработка

Требуются Node.js 24 и npm. Если репозиторий клонирован, выполняйте команды из папки `codex-assistant`.

```powershell
npm.cmd ci
npm.cmd start
```

Сборка Windows:

```powershell
npm.cmd run dist
npm.cmd run dist:portable
```

## Релизы и автообновление

Установщик и portable-версия публикуются в [GitHub Releases](https://github.com/dev-onewizard/dev-onewizard/releases). Чтобы выпустить обновление, увеличьте версию через `npm.cmd version patch --no-git-tag-version`, зафиксируйте изменения и отправьте их в `main`. GitHub Actions соберёт Windows x64 и опубликует выпуск с этой версией.

Для первой установки откройте `Codex-Assistant-Setup-<версия>.exe` из GitHub Releases, выберите папку в мастере и запустите приложение с созданного ярлыка. При запуске установщика более новой версии поверх зарегистрированной установки он использует прежнюю папку и открывает обновлённое приложение.

С включённой настройкой «Загружать обновления автоматически» приложение проверяет релизы при запуске и раз в час. Если проверка при запуске затягивается, главное окно открывается через четыре секунды, а проверка продолжается в фоне. После загрузки нажмите «Обновить» в окне подтверждения. Если выбрать «Отмена», обновление можно запустить позже из настроек. После установки приложение перезапустится с прежними настройками и ярлыками. При выключенной автоматической загрузке проверка доступна вручную.

Переносная версия и запуск из исходников через `npm start` показывают ссылку на новый выпуск для ручной установки.

## Рекламные баннеры

Рабочий баннер Majestic RP лежит в `assets/ads/majestic-promo.png`. Для замены или добавления баннеров положите изображения в `assets/ads` и обновите список `assets/ads/banners.json`. Если у баннера задано поле `promoCode` и указана ссылка HTTPS, нажатие скопирует промокод перед переходом.

```json
[
  {
    "image": "first-banner.webp",
    "title": "Название баннера",
    "url": "https://example.com/"
  }
]
```

Поддерживаются JPG, PNG, WebP и AVIF. Для экрана приложения удобно подготовить изображения примерно 920×128 пикселей. Поле `url` можно пропустить. При нескольких баннерах приложение переключает их каждые 6 секунд и ставит смену на паузу при наведении или фокусе. Точки позволяют переключать баннеры вручную. Чтобы показать баннеры пользователям установленной версии, включите файлы в следующий релиз.

### Подпись сборок Windows

Если издатель использует доверенный сертификат Authenticode в формате PKCS#12, добавьте его в GitHub Actions secrets как `WIN_CSC_LINK` (содержимое `.pfx` в Base64), а пароль как `WIN_CSC_KEY_PASSWORD`. Сборка подписывает приложение, установщик и переносную версию до публикации и проверяет подписи. После подключения подписи задайте переменную репозитория `REQUIRE_WINDOWS_SIGNATURE=true`, чтобы остановить выпуск при отсутствии ключа. Для облачных и аппаратных ключей способ интеграции зависит от сервиса подписи.

## Локальная конфигурация аналитики

Аналитика выключена по умолчанию. Для локального тестирования её можно включить переменными окружения `CODEX_GA_MEASUREMENT_ID` и `CODEX_GA_API_SECRET`; секрет не хранится в репозитории.
