# Codex Assistant

Оверлей-справочник для Majestic RP: быстрый поиск законов и правил поверх игры, выбор сервера, работа с кэшем и обновления приложения через GitHub Releases.

## Возможности

- поиск по кодексам, тексту статьи, пояснениям, исключениям и санкциям;
- вкладки законов и правил, фильтры по разделам и категориям;
- список серверов Majestic, загружаемый из базы проекта;
- офлайн-кэш законов и правил;
- горячая клавиша, авто-скрытие, настройка прозрачности и темы;
- автоматическое получение новых сборок из GitHub Releases.

## База Majestic

Приложение читает список серверов из `repo_structure.json`, кодексы из `laws/` и общие правила из `rules/general.json`, `rules/events.json` и `rules/organizations.json` в [`alamantik/majestic-laws-db`](https://github.com/alamantik/majestic-laws-db). База охватывает 19 серверов Majestic. Приложение сохраняет загруженные данные для доступа без сети. Очистка кэша удаляет эти копии. Сброс настроек возвращает исходные значения в обоих окнах.

## Запуск и разработка

Требуются Node.js 24 и npm. Если репозиторий клонирован, выполняйте команды из папки `codex-assistant`.

```powershell
npm.cmd ci
npm.cmd start
```

Сборка Windows:

```powershell
npm.cmd run dist
npm.cmd run dist:portable
```

## Релизы и автообновление

Установщик и portable-версия публикуются в [GitHub Releases](https://github.com/dev-onewizard/dev-onewizard/releases). Чтобы выпустить обновление, увеличьте версию через `npm.cmd version patch --no-git-tag-version`, зафиксируйте изменения и отправьте их в `main`. GitHub Actions соберёт Windows x64 и опубликует выпуск с этой версией.

Для автообновления один раз запустите `Codex-Assistant-Setup-<версия>.exe` из GitHub Releases и открывайте приложение с ярлыка, созданного установщиком. С включённой настройкой «Автоматическое обновление» приложение проверяет релизы при запуске и раз в час, скачивает обновление и устанавливает его при выходе. Кнопка «Перезапустить и установить» применяет загруженное обновление сразу. Если выключить автообновление, проверить и установить обновление можно вручную в настройках.

Переносная версия умеет проверять релизы автоматически и показывает ссылку на новый файл. При запуске из исходников через `npm start` проверка доступна вручную.

## Локальная конфигурация аналитики

Аналитика выключена по умолчанию. Для локального тестирования её можно включить переменными окружения `CODEX_GA_MEASUREMENT_ID` и `CODEX_GA_API_SECRET`; секрет не хранится в репозитории.
